# Project 0
First project in IN1910 about testing with pytest and git. 

This project implements and tests two main modules:
- A basic calculator module (`calculator.py`) with mathematical functions and associated unit tests.
- A numerical integration module (`numerical_integration.py`) implementing methods like left Riemann sum and midpoint, along with convergence rate testing.
